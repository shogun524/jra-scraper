# JRA競馬AI予測パイプライン

南関東競馬AI・競輪AIと同じ構成(GitHub Actions + GitHub Pages, LightGBM)で作った、
JRA(中央競馬)向けの馬別ランキング予測システム。

## 構成

```
src/feature_engineering.py  raw CSV -> 特徴量テーブル(data/features.parquet)
src/train_model.py          LightGBMで1着確率・3着内確率モデルを学習 + バックテスト
src/predict.py              未来の出馬表(CSV)を入力してランキング予測
src/generate_html.py        予測結果をGitHub Pages用HTMLに変換
.github/workflows/weekly_predict.yml   週末自動実行の雛形(要・出馬表取得ステップ追加)
```

## データ更新と再学習(2026-10 追加)

`race_result_merged.csv`(リリース `data-v1`)は **2022年11月〜2026年7月が丸ごと抜けていた**ため、
出走馬の約7割がデータ上「出走歴なし」になり、AIの確率がどの馬もほぼ同じになっていた
(予測の成績ページで、AIの重み0・1番人気を平均12%と評価、という形で表面化)。

| ワークフロー | 役割 |
|---|---|
| `backfill_history.yml` | 抜けている期間の結果を netkeiba から取り直してリリースを更新。1回5時間で区切り、終わるまで自分を再実行。完了したら再学習を起動。毎週火曜早朝は前回の続きの分だけ取り足す |
| `retrain.yml` | 特徴量作成 → コース集計 → 学習・バックテスト → モデルを main に保存 |
| `results_update.yml` | 予測履歴と確定結果を突き合わせて「予測の成績」ページを更新 |

**初回の穴埋め**: Actions → 「JRA過去結果のバックフィル」→ Run workflow で `start` に `2021-08-01` を入れて実行
(2021-08〜2022年の旧取得分も、芝ダ・クラスの欠損と4コーナー通過順のずれを直すため取り直す)。

同時に直した「学習時と予測時の食い違い」:
- `pace_ratio`(そのレース自身の前半ペース=レース後にしか分からない値)を特徴量から削除
- 頭数・クラス・馬体重増減が予測時に常に欠損/0だったのを、出馬表から取るように修正
- 騎手名の照合を「記号除去+先頭3文字」に統一(結果ページは「ルメー」、出馬表は「ルメール」のため)
- 調教師名の所属表記(美浦/栗東/[東]など)を除去して照合
- 通過順が2コーナー分しかないレースで4コーナーが空欄になっていたのを後ろ詰めに修正

## 買い方別の回収率(実際の払戻で検証、2026-10)

`src/backtest_bets.py` で、AI(2023年までで学習したモデル)の順位と人気順を使った約40通りの買い方を、
実際の払戻(リリース `payouts`、`payouts_backfill.yml` で取得)で検証した。2024年で検証し、2025-01〜2026-10(6,005レース)で確認。
全結果は `data/backtest_bets.csv`。

| 買い方 | 1レースの点数 | 回収率 2024 | 回収率 2025〜 | 95%区間 |
|---|---|---|---|---|
| 複勝 1番人気 | 1 | 85.8% | 84.9% | 83〜87% |
| 複勝 ◎(◎が1番人気のときだけ) | 1 | 84.6% | 85.8% | 84〜88% |
| 馬連 1番人気-2番人気 | 1 | 80.8% | 83.4% | 78〜89% |
| ワイド 1番人気-2番人気 | 1 | 80.8% | 82.0% | 79〜86% |
| 単勝 ◎ | 1 | 79.4% | 77.0% | 73〜81% |
| 3連複 ◎軸-AI2〜5位流し | 6 | 79.1% | 69.3% | 64〜75% |
| 3連複 ◎-AI2,3位-AI2〜8位 | 約11 | 74.6% | 67.8% | 63〜73% |
| 3連単 ◎→AI2,3位→AI2〜5位 | 6 | 74.4% | 61.1% | 51〜72% |

- 100%を超える買い方は無かった(芝ダ・頭数・クラス別に分けても、2024年に100%を超えた条件が2025年以降も続いたものは0)
- 損が小さいのは人気馬の複勝・馬連・ワイド(控除率ぶん程度の80〜86%)。点数を広げた3連複・3連単ほど損が大きい
- AIは「◎が1番人気と一致したときの複勝」などで1ポイント前後よくなる程度で、市場を上回る材料にはなっていない

## 特徴量(43項目)

過去実績はすべて「そのレースより前のデータのみ」を使うリーク防止設計。

- 馬: 直近5走の着順平均/勝率/3連対率、キャリア通算成績、同条件(コース×馬場×距離帯)適性、
  中10週など間隔、脚質(4角通過順位の相対位置)
- 騎手: 直近200騎乗の勝率・3連対率
- 調教師: 通算勝率
- 枠番: コース×馬場×距離帯×枠番ごとの過去勝率(トラックバイアス)
- レース: 芝/ダート、距離、馬場状態、頭数、ラップから算出した相対ペース(ハイペース/スローペース)

**単勝オッズ・人気は特徴量に含めていません。** 市場の評価をそのまま学習すると「市場の受け売り」
になり、市場に対するエッジを測れなくなるためです。モデルは馬の実力のみから確率を出し、
その後に実際のオッズと比較して期待値(EV)を計算します。

## バックテスト結果(2019-01〜2021-07、モデルが学習時に一度も見ていない期間)

| 指標 | 値 |
|---|---|
| 1着モデル AUC | 0.773 |
| 3着内モデル AUC | 0.762 |
| 単勝フラットベット全レースROI(ベースライン) | 73.9% |
| 期待値フィルタ戦略(EV≧1.0〜2.0) ROI | 65〜70% |

**正直な結論: 現時点のモデルだけでは単勝で市場に対するプラスの回収率エッジは確認できていません。**
期待値フィルタで絞ってもROIはベースラインを上回らず、EV閾値を上げるほど平均オッズが上がる
(高配当馬=万人気馬に偏る)ため、むしろ「大穴は割高」という典型的な逆バイアスに引っかかっています。
AUC自体は0.77前後で市場に近い精度は出ていますが、それを上回るエッジではありません。

これは特別に悪い結果ではなく、成熟した控除率20%のパリミュチュエル市場でエッジを見つけるのが
本質的に難しいことを裏付けています(このデータ自体で示した通り、人気順にただ賭けても
回収率は75〜80%に収束します)。「AI予測=回収率100%超え確約」という前提自体が現実的ではありません。

## だからこそ今回の設計方針

ユーザー自身が最終判断できる**ランキング表示**にしています。1着率・3連対率・期待値の
「材料」を提示し、単勝で機械的に賭けるのではなく、馬連・ワイド・3連系などの組み立てや、
自分の目や当日のトラックバイアス情報と併せて判断してもらう前提です。
