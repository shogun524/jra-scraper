# JRA競馬AI予測パイプライン

南関東競馬AI・競輪AIと同じ構成(GitHub Actions + GitHub Pages, LightGBM)で作った、
JRA(中央競馬)向けの馬別ランキング予測システム。

## 構成

```
src/feature_engineering.py  raw CSV -> 特徴量テーブル(data/features.parquet)
src/train_model.py          LightGBMで1着確率・3着内確率モデルを学習 + バックテスト
src/predict.py              未来の出馬表(CSV)を入力してランキング予測
src/generate_html.py        予測結果をGitHub Pages用HTMLに変換
.github/workflows/weekly_predict.yml   週末自動実行の雛形(要・出馬表取得ステップ追加)
```

## 特徴量(43項目)

過去実績はすべて「そのレースより前のデータのみ」を使うリーク防止設計。

- 馬: 直近5走の着順平均/勝率/3連対率、キャリア通算成績、同条件(コース×馬場×距離帯)適性、
  中10週など間隔、脚質(4角通過順位の相対位置)
- 騎手: 直近200騎乗の勝率・3連対率
- 調教師: 通算勝率
- 枠番: コース×馬場×距離帯×枠番ごとの過去勝率(トラックバイアス)
- レース: 芝/ダート、距離、馬場状態、頭数、ラップから算出した相対ペース(ハイペース/スローペース)

**単勝オッズ・人気は特徴量に含めていません。** 市場の評価をそのまま学習すると「市場の受け売り」
になり、市場に対するエッジを測れなくなるためです。モデルは馬の実力のみから確率を出し、
その後に実際のオッズと比較して期待値(EV)を計算します。

## バックテスト結果(2019-01〜2021-07、モデルが学習時に一度も見ていない期間)

| 指標 | 値 |
|---|---|
| 1着モデル AUC | 0.773 |
| 3着内モデル AUC | 0.762 |
| 単勝フラットベット全レースROI(ベースライン) | 73.9% |
| 期待値フィルタ戦略(EV≧1.0〜2.0) ROI | 65〜70% |

**正直な結論: 現時点のモデルだけでは単勝で市場に対するプラスの回収率エッジは確認できていません。**
期待値フィルタで絞ってもROIはベースラインを上回らず、EV閾値を上げるほど平均オッズが上がる
(高配当馬=万人気馬に偏る)ため、むしろ「大穴は割高」という典型的な逆バイアスに引っかかっています。
AUC自体は0.77前後で市場に近い精度は出ていますが、それを上回るエッジではありません。

これは特別に悪い結果ではなく、成熟した控除率20%のパリミュチュエル市場でエッジを見つけるのが
本質的に難しいことを裏付けています(このデータ自体で示した通り、人気順にただ賭けても
回収率は75〜80%に収束します)。「AI予測=回収率100%超え確約」という前提自体が現実的ではありません。

## だからこそ今回の設計方針

ユーザー自身が最終判断できる**ランキング表示**にしています。1着率・3連対率・期待値の
「材料」を提示し、単勝で機械的に賭けるのではなく、馬連・ワイド・3連系などの組み立てや、
自分の目や当日のトラックバイアス情報と併せて判断してもらう前提です。
