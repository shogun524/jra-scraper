# JRA競馬AI予測パイプライン

南関東競馬AI・競輪AIと同じ構成(GitHub Actions + GitHub Pages, LightGBM)で作った、
JRA(中央競馬)向けの馬別ランキング予測システム。

## 構成

```
src/feature_engineering.py  raw CSV -> 特徴量テーブル(data/features.parquet)
src/train_model.py          LightGBMで1着確率・3着内確率モデルを学習 + バックテスト
src/predict.py              未来の出馬表(CSV)を入力してランキング予測
src/generate_html.py        予測結果をGitHub Pages用HTMLに変換
.github/workflows/weekly_predict.yml   週末自動実行の雛形(要・出馬表取得ステップ追加)
```

## 特徴量(51項目)

過去実績はすべて「そのレースより前のデータのみ」を使うリーク防止設計。

- 馬: 直近5走の着順平均/勝率/3連対率、キャリア通算成績、同条件(コース×馬場×距離帯)適性、
  中10週など間隔(カテゴリ化: 連闘/中1-3週/中4-8週/久しぶり)、脚質(4角通過順位の相対位置)、
  **前走そのものの着順**、**前走からの距離変化・斤量変化**、**クラス格付け**(新馬〜オープンを序列化)
- 騎手: 直近200騎乗の勝率・3連対率
- 調教師: 通算勝率
- **騎手×調教師コンビ**: そのコンビでの過去勝率(主戦騎手としての強さを捉える)
- 枠番: コース×馬場×距離帯×枠番ごとの過去勝率(トラックバイアス)
- レース: 芝/ダート、距離、馬場状態、頭数、ラップから算出した相対ペース(ハイペース/スローペース)

単勝オッズ・人気は特徴量に含めていません(理由は次項)。

## データ範囲と既知の制約

- 元データ: 1986-01-05 〜 2021-07-31(1,626,811行)
- 追加取得分: 2021-08-01 〜 2022年途中まで(61,266行。netkeiba側のアクセス制限により
  2023年以降は取得できていない。詳細は本文参照)
- 追加取得分は**約半数の行で芝・ダート区分/距離が欠損**(スクレイパーの表記揺れ対応が後追いで
  完了したため。バグ自体は修正済みで、次回追加取得分からは解消される見込み)
- 追加取得分は**調教師名の表記が新旧で異なる**(旧:フルネーム、新:所属+姓のみ)ため、
  2021年8月の境目で調教師の成績が一部リセットされる
- **競争条件(クラス格付け)は追加取得分には含まれておらず欠損**(新規スクレイパーが未対応のため)

## バックテスト結果(2021-08〜2022年、モデルが学習時に一度も見ていない期間)

| 指標 | 値 |
|---|---|
| 1着モデル AUC | 0.775 |
| 3着内モデル AUC | 0.766 |
| 単勝フラットベット全レースROI(ベースライン) | 71.3% |
| 期待値フィルタ戦略(EV≧1.0〜2.0) ROI | 56〜63% |

**正直な結論(前回と変わらず): 単勝では市場に対するプラスの回収率エッジは確認できていません。**
新しい特徴量(前走着順・クラス格付け・距離/斤量変化・騎手×調教師コンビ)はモデルの分類精度自体には
寄与しましたが(AUCはほぼ同水準を維持)、期待値フィルタで絞ってもROIはベースラインを上回らず、
高配当馬に偏る逆バイアスも変わらず見られます。特徴量を増やしても市場平均を上回るエッジが
自動的に生まれるわけではない、という点はこのデータセット・このアプローチの限界として
正直にお伝えします。

これは特別に悪い結果ではなく、成熟した控除率20%のパリミュチュエル市場でエッジを見つけるのが
本質的に難しいことを裏付けています(このデータ自体で示した通り、人気順にただ賭けても
回収率は75〜80%に収束します)。「AI予測=回収率100%超え確約」という前提自体が現実的ではありません。

## だからこそ今回の設計方針

ユーザー自身が最終判断できる**ランキング表示**にしています。1着率・3連対率・期待値の
「材料」を提示し、単勝で機械的に賭けるのではなく、馬連・ワイド・3連系などの組み立てや、
自分の目や当日のトラックバイアス情報と併せて判断してもらう前提です。

## 出馬表からの予測時の重要な安全装置(2026-08-30 修正)

`predict.py`は、DB(`race_result_merged.csv`)上でその馬の最終戦が**180日以上前**の場合、
直近成績だけでなくキャリア通算成績・距離適性まで含めて、その馬固有の特徴量をすべて
「不明」として扱う。理由: DBの更新が止まっている馬(=直近にnetkeibaから再取得できていない馬)
について、古い時代の成績をそのまま使うと、引退間際で成績が落ちている馬を
「勝率2割の実力馬」のように誤って評価してしまうことが実際に確認された
(2026年新潟記念の実データでの検証で、11番人気・73倍だった馬を2位評価してしまうバグを発見・修正)。
この安全装置がある限り、DBの更新が古いままでも「変な自信過剰」は起きにくいが、
根本的には直近結果を継続的に取り込み続けることが望ましい。
